 # **Tharaa** Platform Visual Identity
## Detailed Design Specification

Based on the platform's nature (Arabic interactive financial education) and the attached documents, here is the precise visual identity description:

---

## 1. Visual Philosophy

```
Tone: Friendly × Trustworthy × Modern × Inspiring
Feeling: Financial Safety + Learning Joy + Personal Progress
Direction: Minimalist Functional with Gamification Touches
```

**Visual Message:**  
"A platform that looks serious enough to manage your money, and fun enough to make learning a daily habit."

---

## 2. Color System

### Primary Colors

| Color | Hex Code | Usage |
|-------|----------|-------|
| **Tharaa Green** | `#0A8554` | Primary buttons, navigation bar, positive financial indicators, income icons |
| **Tharaa Gold** | `#D4A843` | Main headings, achievements, points (XP), badges, visual distinction for completed goals |
| **Tharaa Navy** | `#1B2A4A` | Header backgrounds, heading text, high contrast, footer |

### Secondary Colors

| Color | Hex Code | Usage |
|-------|----------|-------|
| **Sky Blue** | `#3B82F6` | Links, secondary buttons, educational information |
| **Alert Red** | `#DC2626` | Expenses, budget overruns, errors, urgent notifications |
| **Mint Green** | `#34D399` | Success notifications, completed lessons, positive progress |
| **Purple Accent** | `#7C3AED` | Gamification, advanced levels, rare badges |

### Neutral Colors

| Color | Hex Code | Usage |
|-------|----------|-------|
| **Main Background** | `#F8FAFC` | Page backgrounds |
| **Card Background** | `#FFFFFF` | Cards, modals, containers |
| **Light Border** | `#E2E8F0` | Borders, dividers |
| **Primary Text** | `#1E293B` | Headings, body text |
| **Secondary Text** | `#64748B` | Descriptions, metadata, timestamps |
| **Disabled Text** | `#94A3B8` | Placeholders, disabled states |

### Custom Gradients

```css
/* Primary gradient for buttons and prominent elements */
--gradient-primary: linear-gradient(135deg, #0A8554 0%, #059669 100%);

/* Gold gradient for achievements */
--gradient-gold: linear-gradient(135deg, #D4A843 0%, #F59E0B 100%);

/* Hero Section background gradient */
--gradient-hero: linear-gradient(180deg, #1B2A4A 0%, #0F172A 100%);
```

## 3. Typography

### Arabic Fonts

| Purpose | Font | Weight | Fallback |
|---------|------|--------|----------|
| **Main Headings** | Tajawal | ExtraBold (800) | Cairo |
| **Subheadings** | Tajawal | Bold (700) | Cairo |
| **Body Text** | Tajawal | Regular (400), Medium (500) | Noto Sans Arabic |
| **Numbers & Data** | IBM Plex Sans Arabic | Medium (500) | Vazirmatn |

### English Fonts (for numbers and symbols)

| Purpose | Font |
|---------|------|
| **Financial Numbers** | Inter, Tabular Figures |
| **Code & Programming** | JetBrains Mono |

### Typography Scale (Arabic RTL)

```
Hero Title:           48px / 1.2 / Tajawal ExtraBold
Main Heading (H1):    32px / 1.3 / Tajawal Bold
Sub Heading (H2):     24px / 1.4 / Tajawal Bold
Third Heading (H3):   20px / 1.4 / Tajawal Bold
Large Body:           18px / 1.8 / Tajawal Regular
Normal Body:          16px / 1.7 / Tajawal Regular
Small Body:           14px / 1.6 / Tajawal Regular
Caption/Label:        12px / 1.5 / Tajawal Medium
```

**RTL Rules:**
- `line-height` 20% higher than Latin (1.6-1.8)
- `letter-spacing: 0` for Arabic
- `text-align: right` by default
- Full support for Arabic and Hindi numerals

## 5. Iconography

| Set | Usage | Size |
|-----|-------|------|
| **Heroicons** | General UI icons | 20px - 24px |
| **Phosphor Icons** | Interaction and state icons | 16px - 32px |
| **Custom SVG** | Gamification and badge icons | 40px - 64px |
| **Lucide** | Data and chart icons | 16px - 20px |

**Icon Rules:**
- Stroke width: 1.5px - 2px
- Line-cap: round
- Color follows context (green for income, red for expense, gold for achievement)
- Financial status icons are circular with a light background

## 6. Gamification Visual Elements

### Progress Ring
```css
.progress-ring {
  stroke: #E2E8F0;           /* Background track */
  stroke-width: 8;
  fill: none;
}

.progress-ring-fill {
  stroke: url(#gradient-gold); /* Progress fill */
  stroke-linecap: round;
  transition: stroke-dashoffset 0.5s ease;
}
```

### Badges & Achievements
- **Shape:** Hexagonal or circular with a gold edge
- **Size:** 48px - 64px
- **Effect:** Subtle "shine" effect when badge is earned
- **Colors by tier:**
  - Bronze: `#CD7F32` (simple achievements)
  - Silver: `#C0C0C0` (medium achievements)
  - Gold: `#D4A843` (major achievements)
  - Platinum: `#7C3AED` (rare achievements)

### Experience Points (XP)
```css
.xp-badge {
  background: linear-gradient(135deg, #D4A843, #F59E0B);
  color: #1B2A4A;
  border-radius: 9999px;      /* Pill shape */
  padding: 4px 12px;
  font-weight: 700;
  font-size: 14px;
  box-shadow: 0 2px 8px rgba(212, 168, 67, 0.3);
}
```

```

```

  0%, 100% { transform: translateX(0); }

| Element | Duration | Type |
|---------|----------|------|
| Button Hover | 200ms | ease |

| Chart Update | 500ms | ease-out |
| Notification Entry | 400ms | spring |
| Number Update | 800ms | ease-out |
